# Fluent Reader 自用版使用说明

适用于 Fluent Reader Personal 1.3.2-personal.6。

## 安装与第一次使用

运行文件名中含 `Setup-x64.exe` 的安装包，选择安装位置。也可以解压便携 ZIP 后运行 `Fluent Reader Personal.exe`，保留同目录的其他文件。

此版本使用独立名称和数据目录，避免覆盖原版。升级自用版时直接安装新版本，数据库会自动迁移。卸载默认保留阅读数据。首次使用建议先设置备份文件夹，再添加订阅。

## 及时更新与刷新结果

启动后自动检查订阅，点击顶部刷新按钮或按 **F5** 可立即重新检查全部订阅。手动刷新不受单个订阅源设置的最小间隔限制。

未设置过自动刷新时，默认在软件运行期间每 **10 分钟** 检查。可在选项中的自动抓取频率中调整或关闭；以前明确选择“关闭”的设置会保留。自动检查还会遵守订阅源或分组的最小刷新间隔，例如源设置 60 分钟时，不会每 10 分钟都请求它。开启自动刷新后，回到软件会检查是否已到时间，恢复联网后会补做检查；重复触发不会同时发起多轮刷新。

顶部显示最近完成刷新的时间、新增篇数和失败数量。“新增 0 篇”表示没有新的文章入库；如有失败，打开通知查看具体原因。超过 30 秒仍未收完的订阅请求会结束等待，可重新刷新。订阅健康页可以查看各源的成功抓取时间、最近检查时间和本地最新文章发布时间，也可以单独立即刷新一个源。健康检查只检查可用性，成功抓取时间在实际导入成功后更新。

文章卡片上的“5h”等相对时间按 RSS 提供的**发布时间**计算。将鼠标放在时间上，可以同时查看发布时间和**本地收到时间**。刚收到一篇较早发布的文章，仍可能显示数小时前；这不等于软件已经几小时没有刷新。

本地阅读器完全退出后不会继续收集；网站 RSS 往往仅保留最近一部分文章，关闭期间已经滚出列表的内容可能无法补回。需要尽量完整地收集高频订阅时，可让应用在电脑运行期间保持打开，或在“服务”中配置已有云端阅读服务，再同步其持续收集的文章。云端服务是否保存完整历史取决于其自身规则。软件不会自动登录或新建服务。

## 搜索所有文章内容

点击顶部的“全文搜索”，或按 **Ctrl+Shift+F**。输入中文或英文即可查找标题、RSS 提供的正文、抓取过的全文和离线页面正文。多个词用空格分隔，结果需要同时包含这些词。

结果按相关程度排列，命中处标黄。点击标题阅读文章；底部可加载更多结果。首次升级时会后台建立索引，窗口里能看到进度。尚未抓取或保存的网页内容不会凭空出现在索引中。

原来的 **F2** 搜索仍用于当前列表的关键词包含、排除和正则筛选。

## 备份与恢复

打开“选项 → 自用功能”，在“备份与恢复”中选择备份文件夹。点击“立即备份”会生成一个 ZIP，包含数据库、设置、规则、订阅列表、AI 缓存和已经保存的离线 HTML。如果离线文件被手动删除，备份会提示具体文件，不会默默生成不完整的备份。

可选每天或每周自动备份，默认保留最近 10 份。修改后点击页面顶部的“保存设置”。应用关闭时不会执行备份；下次启动会补做错过的备份。

恢复时点击“从 ZIP 恢复”，选择备份后确认。应用校验文件后重启，替换数据库和设置。替换前的数据会留在应用数据目录的 `before-restore` 文件夹中。离线文件恢复到新的 `offline-restored-…` 子目录，文章会自动指向恢复的副本。恢复不会要求删除现有数据目录。旧版只含数据库的备份仍可恢复。

网站登录 Cookie 不包含在 ZIP 中，恢复到另一台机器后需重新登录。AI 密钥和同步服务凭据均与 Windows 账号绑定，换电脑或账号后需重新填写。已有同步服务的密码、令牌会自动加密迁移，文章和订阅不受影响。

## 登录网站并抓取全文

在“选项 → 自用功能 → 账号与登录”输入网站地址，点击“打开登录窗口”，像普通浏览器一样登录。关闭登录窗口后，网页模式和全文抓取都会使用这份登录状态。点击“刷新账号列表”查看已保存 Cookie 的站点。

在文章里点击“抓取全文”。抓到的正文会保存在数据库中，下次打开直接读取。需要更新正文时，在文章“更多”菜单点“重新抓取全文”。

网页内容依赖 JavaScript 时，在“网站正文提取规则”中填写域名，选择“渲染后提取”，加入规则后保存设置。普通网站保持“直接请求”即可。如果正文提取不准，可以指定正文区域和应移除区域的 CSS 选择器；不熟悉选择器时留空。

“退出此站登录”会清除该域名的登录和网站本地存储。网站也可能主动让登录过期，此时需要重新登录。

## 后台访问速度

“后台任务与访问间隔”默认同一域名至少间隔 5 秒，总并发 1。即使提高总并发，同一域名仍只会运行一项任务。这里会列出任务完成或失败情况。

## 图片与关键词筛选

订阅源中提供的图片附件、媒体缩略图、相对图片地址和常见延迟加载图片都可用于卡片。图片仍需网站允许访问，已失效或需要额外认证的图片可能无法显示。

现有关键词规则支持屏蔽和只保留匹配内容；关键词用逗号、分号或换行分隔。规则对新抓取文章生效，已有文章可用 F2 立即筛选。被隐藏的文章可以通过列表显示选项重新查看。

## 每个源用不同的设置

右键订阅源，选择“源与分组设置”。也可在订阅源设置页选中多个源批量修改；分组设置页可修改整个分组的默认值。

“继承默认值”表示使用分组设置。源上单独设置的值优先，批量修改只应用本次调整过的项目。全文方式关闭时，这个源的文章不再显示全文按钮。

## 多条件规则与标签

在“选项 → 规则”选择全部文章、某个分组或某个源。新建规则时选择“多条件与动作”，填入标题、正文、作者或链接条件，并选择全部满足或任一满足。勾选需要的动作，可同时选择高亮颜色和多个标签。

“预览最近 100 篇”只检查匹配，不会改变现有文章。规则保存后对新文章生效；拖动规则可调整顺序，关闭开关可暂时停用。系统通知是否显示横幅还取决于 Windows 通知设置。

文章的“更多”菜单或列表右键菜单可编辑标签；打开左侧菜单后点击 `#标签名` 即可浏览。

## 保存网页到本地

文章工具栏或列表右键菜单选择“保存到本地”。需要登录的页面先在账号管理里登录。保存过程会等待页面加载并滚动触发图片，再把页面存成单个 HTML。

在“选项 → 自用功能”可指定保存根目录，并查看任务状态、失败原因和重试按钮。默认放在应用数据目录的 offline 文件夹。文件按“源名/日期/标题”排列，同名会自动编号。

保存后的文章会显示 ▣ 标记；在“更多”或右键菜单选择“查看本地副本”，使用系统浏览器打开。也可“在文件夹中显示”。离线文件中的文字可用全文搜索找到。视频等动态内容及受限制的资源可能无法保留。

源设置里的“刷新时自动离线保存”，以及规则里的“离线保存”动作，使用同一后台队列。当前 ZIP 备份会包含这些 HTML 文件，也可以直接复制保存目录到其他磁盘保管。

## 稍后读与自动过期

### 筛选归档与文章文件夹（personal.5）

顶部“快捷标为已读”保留 **1 天前** 等快捷选项，处理当前列表筛选范围内超过 24 小时的文章。选中卡片后，操作条直接处理已选文章：已读、收藏、稍后读、加入文件夹和更多操作，不再要求日期筛选；完成后可撤销。

点击顶部 **筛选归档** 或按 **F6**，输入“包含这些内容”“排除这些内容”。关键词或短语用逗号、分号、换行分隔，可选任意满足或全部满足；普通输入按字面匹配，不需要写正则。默认搜索整个本地文章库的标题和已有正文，包含已缓存的全文和离线文字。高级条件提供正则、大小写和日期。

同一窗口显示全部命中数量及分批预览，可取消本次不想处理的文章。选择“归入文件夹”，直接选择已有文件夹或点击“新建「关键词」”；展开“新建文件夹”可改名或指定上级。选择“只看匹配文章”则在主列表浏览本次结果，不修改状态。

“归档后从订阅流隐藏”只影响订阅源、订阅分组和全部订阅；不会删除或标读，文件夹、收藏、稍后读及全文搜索仍可找到。高级操作“恢复到订阅流”可恢复。默认归档保留订阅流显示。

“以后自动执行此规则”默认关闭，勾选后用于未来收到的文章。可以只保存规则，允许当前零命中。日期和逐条排除只用于本次，不保存到未来规则。在“选项 → 规则 → 筛选归档规则”编辑、暂停、删除或整理现有文章；删除规则保留过去已做的分类。

侧栏“管理文章文件夹”支持新建、重命名、移动和删除两级文件夹，例如“技术 / AI”。可把一个文件夹拖到一级文件夹下。父目录包含子目录文章并去重，一篇文章可以加入多个文件夹。从当前文件夹“移动”只移出该起点，其他分类保留。删除文件夹保留文章，无其他分类的文章进入“未分类资料”。

打开文章后的“备注与归类”可写备注、查看和调整分类；备注自动保存，失败时保留输入并提供重试。备注可用全文搜索查找。收藏、稍后读、已分类和有备注的资料受到保护，常规清理与取消订阅会保留它们及来源信息。

旧版“主题/名称”自动迁移为文章文件夹，普通标签保留；旧规则产生的主题继续映射到原文件夹，改名不会改变关联。首次迁移前保留 before-article-library 数据库和配置副本。完整 ZIP 备份包含所有文件夹、备注、规则及离线文件；传统 .frdata 包含文章库和缓存文字，不携带独立离线 HTML 文件，跨电脑完整迁移建议用 ZIP。

### 集中阅读与列表空间

“稍后读”“收藏”分别记住卡片/列表/杂志/紧凑视图。进入集合后，顶部阅读方式可选跟随订阅源、RSS 正文、内置网页或全文；此选择优先于源默认打开方式，选择全文可覆盖源的关闭抓取设置，但仍遵守站点级禁用规则。普通订阅浏览视图不受影响。

在列表视图点击“折叠文章列表”，让出右侧网页空间。移到左边缘可临时展开，移出后收起；点击“固定展开”恢复常驻。边缘按钮可用 Tab 定位后按 Enter 展开。折叠不重新创建网页，因此保留当前网页滚动和登录状态。

侧栏文章集合数字是总篇数，包含已读与从订阅流隐藏的资料。关键词和仅未读筛选可能使实际列表少于总数。顶部“含已读 / 仅未读”可快速切换；隐藏文章另由视图菜单控制。往返订阅与集合时会保留本次运行期间的浏览位置；位置锚点文章被移出时回退到邻近位置。

“选项 → 自用功能”顶部提供分类入口，账号登录、全文站点规则、离线保存、AI、备份等无需在同一个长页中寻找。分类之间切换保留已输入内容；修改后使用“保存设置”。AI 配置仍使用自己的保存按钮。

文章里点击时钟按钮或按 **R**，加入或移出稍后读；收藏仍用星标或 **S**。左侧菜单分别提供“稍后读”和“收藏”。稍后读列表可一键清除已经读过的条目，也可在自用设置中开启“文章标记已读时自动移出稍后读”。

在源或分组设置里填写“未读过期天数”。例如 7 天，会将超过 7 天的普通未读文章标为已读，不删除正文；收藏和稍后读不受影响。0 表示关闭。打开应用、刷新完成后和运行期间会检查。

全部快捷键可在“选项 → 自用功能 → 快捷键”查看。

## 找到订阅源与检查订阅健康

在“选项 → 订阅源”的输入框粘贴网站首页或 RSS/Atom 地址，点击“添加”。直接的订阅地址会加入订阅；网页中找到多个订阅源时，会列出候选项供你选择。未找到时可打开 RSSHub 查找路由。“选项 → 自用功能”可修改 RSSHub 实例地址。

订阅页的“订阅健康”列出每个源的更新数、打开数、打开率、连续错误和过久未更新的提示。点击“立即检查订阅”检查当前地址和永久跳转；确认后点击“更新订阅地址”应用跳转。低打开率只提示考虑退订，不会删除订阅。同步服务管理的源仍由服务自身检查。

统计覆盖最近 30 天发布的文章，只把实际打开文章或原文计为打开，批量标为已读不会提高打开率。首次升级后，阅读统计从你开始使用本版本起积累。

## AI 摘要、翻译与简报

在“选项 → 自用功能 → AI 设置”填写接口基础地址、模型名和 API 密钥，点击“保存并测试连接”。基础地址通常包含 `/v1`，不要追加 `/chat/completions`。可使用兼容此接口的 DeepSeek、通义或本地 Ollama 等服务；具体地址和模型名按服务商说明填写。本地服务不要求密钥时可留空。

密钥加密保存在本机；修改服务商地址会清除旧地址的密钥，避免误发。未配置地址和模型时，阅读界面隐藏 AI 按钮。使用 AI 时，文章文字会发送给你选择的服务商，产生的费用由该服务商计费。

在源或分组设置中打开“启用 AI”，文章工具栏会出现“生成摘要”和“全文翻译”。翻译时优先抓取网站全文（按该源设置使用登录态），与原文并排显示；若关闭全文抓取，则翻译已有正文。长文会分段处理，耗时可能较长。切换文章或关闭窗口不会取消已提交给服务商的请求，结果仍会缓存。

同一源可开启“自动翻译标题”和“自动生成摘要”，对刷新时收到的新文章生效。原标题保留，卡片鼠标悬停可查看。相同文章内容、模型、地址和目标语言会复用缓存；正文变化或修改模型后才会重新生成。

左侧菜单“每日简报”可立即汇总过去 24 小时的未读、未隐藏文章，按主题排列；点击标题在应用内阅读，点击“打开原文网页”用浏览器打开。历史简报可回看。也可在 AI 设置中启用每日定时生成；应用关闭时不会运行，下次打开会补生成。

结果显示对应 token 数，设置中显示上次调用和本月累计用量。服务商没有报告用量时会明确说明，不会编造数字。连接、配额或格式报错会显示在界面，修正设置后可重试。

## 验证范围与已知限制

此版本已使用本地测试站验证登录、全文、图片离线保存、搜索、备份恢复、规则和 AI 接口流程。六种同步服务做了模拟协议回归；真实账号的登录与服务商差异仍取决于你使用的服务。未使用任何个人账号密钥或付费 AI 额度进行验收。

首次建立大库索引时搜索内容会逐步补齐。视频、需要交互才能显示的内容、拒绝资源下载的站点无法保证完整离线还原。网站自行撤销的登录状态仍需重新登录。

## Linux.do 论坛阅读

在“选项 → 订阅源”展开 **LINUX DO → 选择订阅**。推荐添加“最新主题”；“最新回复”包含回复楼层。可直接添加常用分类，在“分类”读取网站目录，或在“标签”输入 codex、grok 等名称搜索并订阅。新订阅自动放入 Linux.do 分组，已订阅的项目不可重复添加。原站提供的 RSS 标签随新文章保存。

Linux.do 单源或分组默认使用三栏列表，单源列表显示作者与主题/回复楼层，过滤表情和头像封面。切换单个订阅的视图后会记住选择。“今日热门”展示站点榜单条目；“每小时热门榜单”每小时最多保存一次发生变化的榜单，升降与上次保存结果比较，保留近期 24 次快照供导入，需应用持续运行。排名不代表账号等级。

**账号与等级帖（实验）**：点击“打开 Linux.do 登录窗口”，在网站完成登录与验证，再点击“检查账号可读内容”。成功后显示账号等级、当前返回主题数、识别到的限定分类主题数。可订阅账号可见新主题或具体限定分类。只使用该账号实际可访问的内容；列表先保存标题与索引摘要，打开文章后点击“抓取全文”读取主楼。部分站点接口可能受限，检查失败时按提示重新登录，不等于账号没有权限。实验入口不保证完整历史或所有等级帖均可采集。

账号 Cookie 只保存在应用自身的网站会话中，不出现在订阅 URL 中；更换电脑需重新登录。取消登录后账号订阅会报错，已保存文章保留。

本轮实测限制：2026-11-15，用户反馈普通浏览器可以登录，但应用内窗口出现 Cloudflare 验证循环。因此当前机器上的等级帖采集**尚未验证成功**。程序遇到该状态会暂停账号请求；可以用面板中的“用系统浏览器打开”继续阅读，但不会导入外部浏览器的 Cookie。Discourse 官方用户授权接口是后续可研究方向，尚未确认 Linux.do 是否开放。

在“订阅发现”输入首页、标签、分类或主题页面，程序读取页面明确提供的 RSS 地址。公开首页提供 **最新主题 latest.rss** 和 **最新帖子 posts.rss**；希望主要看新主题时选择前者，后者也会包含回复。不同页面和登录状态可能提供不同入口，以实际发现结果为准。

优先阅读 RSS 已有正文。需要全文时可“抓取全文”，Linux.do 主题链接按主楼提取；明确指向回复的链接只提取对应楼层。找不到目标楼层或需要登录时会提示，不用登录页、整页回复替代正文。需要 JavaScript 或登录时，先在“账号与登录”打开网站登录，再选择渲染后提取；浏览更多回复可打开原帖。

正文保留引用、代码、折叠内容、图片和表格；长代码、宽表格可横向滚动。文件夹把同一 Linux.do 帖子跨订阅的重复条目合并显示，原订阅关系仍保留，不会按相同标题合并不同主题或楼层；写有独立备注的副本分别保留。已抓取正文直接读取缓存，网站限流时延迟同域后续请求，不影响已保存内容。

本版参考 yarr 的订阅发现和缓存使用方式。yarr 文档中的 `/rss/from/<订阅链接>` 输出的是它已收集的内容，不会补抓历史。已有 yarr 服务时可添加该服务提供的 RSS；本软件不需要部署 yarr，也没有声称提供绕过网站访问限制的能力。
