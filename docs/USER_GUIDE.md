# Fluent Reader 自用版使用说明

适用于 Fluent Reader Personal 1.3.2-personal.8。

## 安装与第一次使用

运行文件名中含 `Setup-x64.exe` 的安装包，选择安装位置。也可以解压便携 ZIP 后运行 `Fluent Reader Personal.exe`，保留同目录的其他文件。

此版本使用独立名称和数据目录（`%APPDATA%\Fluent Reader Personal`），避免覆盖原版。升级自用版时直接安装新版本，数据库与旧版规则会自动迁移。卸载默认保留阅读数据。首次使用建议先在“选项 → 自用功能 → 离线与备份”中设置备份文件夹，再添加订阅。

## 及时更新与刷新结果

启动后自动检查订阅，点击顶部刷新按钮或按 **F5** 可立即重新检查全部订阅。手动刷新不受单个订阅源设置的最小间隔限制。

未设置过自动刷新时，默认在软件运行期间每 **10 分钟** 检查。可在选项中的自动抓取频率中调整或关闭；以前明确选择“关闭”的设置会保留。自动检查还会遵守订阅源或分组的最小刷新间隔，例如源设置 60 分钟时，不会每 10 分钟都请求它。开启自动刷新后，回到软件会检查是否已到时间，恢复联网后会补做检查；重复触发不会同时发起多轮刷新。

后台刷新新入库的文章会在左侧边栏“全部文章”、分组与订阅源旁安静显示蓝色 `(+N)` 新增计数，点进对应列表浏览或将文章标为已读后自动消退。顶部显示最近完成刷新的时间、新增篇数和失败数量。“新增 0 篇”表示没有新的文章入库；如有失败，打开通知查看具体原因。订阅健康页可以查看各源的成功抓取时间、最近检查时间和本地最新文章发布时间。

文章卡片上的“5h”等相对时间按 RSS 提供的**发布时间**计算；鼠标悬停在时间上可同时查看发布时间和**本地收到时间**。卡片上半区点击标题进入阅读，下半区勾选框支持直接多选批量处理而不误标已读。

本地阅读器完全退出后不会在后台驻留收集；需要 24 小时不漏抓高频滚动源时，可在电脑运行期间保持应用打开，或在“选项 → 服务”中接入自建 Miniflux、FreshRSS（Google Reader API）、Fever 等同步服务。

## 搜索所有文章内容

点击顶部的“全文搜索”，或按 **Ctrl+Shift+F**。输入中文或英文即可查找标题、RSS 正文、抓取过的全文、离线页面文字以及你的文章备注。多个词用空格分隔，结果需同时包含这些词；支持上下方向键选条与回车直接打开阅读。

首次升级或导入大库时会在后台分批建立 FTS5 索引，搜索框上方实时显示进度。原来的 **F2** 搜索仍用于当前列表内的即时关键词与正则筛选。

## 双栏设置中心与代理配置

点击顶栏齿轮或按 **F9** 打开双栏设置中心：左侧按分类切换面板，右侧常规开关、备份计划、访问间隔与提取规则均为**即时自动保存**（无需再点页面顶部的全局保存按钮；注意备份与离线目录请勿选在软件安装目录内）。

在“选项 → 应用 → 网络代理”中支持直接填写 `127.0.0.1:7890`、`http://...` 或 `socks5://...` 地址并切换代理模式，修改后免重启立即对订阅拉取、全文提取、登录窗口与 AI 请求生效。

## 备份与恢复

在“选项 → 自用功能 → 离线与备份”中选择备份文件夹。点击“立即备份”会生成一个完整 ZIP，包含在线热备数据库 `fluent-reader.db`、配置文件 `config.json`、活跃订阅 `subscriptions.opml`、带 SHA-256 清单的 `manifest.json` 以及已保存的本地离线 HTML。若个别离线文件在磁盘上缺失，备份完成后会明确提示缺失篇数，其余数据正常打包。

可选每天或每周自动备份，默认保留最近 N 份。应用关闭期间错过的定时备份会在下次启动时自动补做。

恢复时点击“从 ZIP 恢复”，程序先在 `pending-restore` 目录完成 SHA-256 与 SQLite `integrity_check` 自检，确认重启后替换数据库和设置，并将替换前的原数据库（连同 `-wal`）完整保存在数据目录的 `before-restore` 文件夹中以备回滚；离线文件恢复到新的 `offline-restored-…` 子目录并自动更新路径。传统 `.frdata` 便携文件包含订阅、文章、两级文件夹、备注、规则与简报文字（不含本地离线 HTML 副本），跨电脑完整迁移推荐使用 ZIP 备份。

网站登录 Cookie 保存在本机独立沙箱会话中，不包含在备份包内，换机后重新登录即可；AI 密钥与同步服务凭据由系统 `safeStorage` 加密绑定当前系统账号，换电脑或系统账号后重新填写即可恢复连接。

## 登录网站、提取全文与阅读排版

在“选项 → 自用功能 → 账号与正文提取”输入网站地址，点击“打开登录窗口”完成登录后关闭窗口，内置网页模式、全文抓取与单文件离线保存都会共享该隔离沙箱会话（跨站子资源与跨站跳转会自动剥离登录凭据以保护账号安全）。“退出此站登录”会一并清理主域与子域的 Cookie 及本地存储。

在文章工具栏点击“抓取全文”（或按 **W**）即可提取干净正文并缓存到本地库；依赖前端渲染的网站可在“网站正文提取规则”中将该域名设为“渲染后提取”，或配置正文/移除元素的 CSS 选择器并现场预览效果。

阅读器顶栏提供 **Aa** 排版面板（独立调节字号、窄/标准/宽版心与行距）、页内查找（**Ctrl+F**）、代码块语言标签与一键复制、图片点击灯箱缩放预览，以及选中正文右键“摘录到文章备注”或“AI 翻译选中段落”。

## 单窗口筛选归档、两级文件夹与自动规则

点击顶栏 **筛选归档**（或按 **F6**），即可在同一窗口内按包含词、排除词、多条件组合或隔离正则搜索整个本地文章库并实时预览命中条目（可逐条勾选排除本次不想处理的文章）。

可选动作包括：归入两级文章文件夹（如“技术 / AI”，可选“归档后从订阅流隐藏”）、标为已读/未读、星标收藏、加入稍后读、桌面通知或加入后台离线保存队列；执行后支持一键撤销。勾选“保存为长期自动规则”后，未来新拉取入库的文章会自动按规则归类处理，所有规则统一在“选项 → 规则”中集中管理、启停、编辑或直接对现有文章库运行（旧版 `#标签` 已在升级时自动平滑迁移合并为文章文件夹，不再占用侧栏）。

打开文章后点击“备注与归类”（或按 **N**）可随时记录自动保存备注并点击胶囊快速归入/移出文件夹。星标收藏、稍后读、文件夹内文章、写有备注或已离线保存的资料均受防删保护，常规按天数清理旧文章与退订源时都会完整保留。

## 保存网页到本地与稍后读

在文章工具栏或列表右键菜单点击“保存到本地”，后台同域限流队列会用隐藏沙箱窗口等待页面与图片加载后打包为单个独立 HTML 文件（默认存于数据目录 `offline/` 下，按“源名/日期/标题”归档，并在左侧边栏“离线网页”集合中集中浏览）。

在文章里点击稍后读按钮或按 **R** 加入“稍后读”。开启“文章标记已读时自动移出稍后读”后，从稍后读点开阅读的文章会等你**切到下一篇或关闭阅读窗时**再移出列表，不会在阅读中途突然从眼前消失。

## 订阅源偏好、发现与健康检查

右键任意订阅源或分组可打开“阅读、AI 与离线偏好”，按“源覆盖 > 分组默认 > 全局默认”继承默认打开方式、最小刷新间隔、未读过期天数、全文提取模式及 AI/自动离线开关。集合（稍后读、收藏、离线网页、各文件夹）也各自独立记忆视图样式与阅读打开方式。

在“选项 → 订阅源”粘贴网站主页即可自动发现 RSS/Atom 候选源；在“选项 → 自用功能 → 网络与订阅健康”可查看近 30 天各源更新量、实际点开阅读率、连续报错与永久重定向检测结果，一键应用新订阅地址。

## 双模型流式 AI 摘要、段落双语翻译与每日简报

在“选项 → 自用功能 → AI 设置”支持保存多套服务商配置档案（内置 DeepSeek、硅基流动、通义千问、智谱、Kimi、OpenRouter、OpenAI、Gemini、Ollama / LM Studio 本地与局域网私有地址预设），每套档案的 API Key 独立加密存储，支持一键拉取 `/models` 模型列表，并可分别为**摘要/简报**与**全文/标题/划词翻译**指定不同模型（例如快模型译标题、主力模型做总结）。

打开文章点击“AI 摘要”或“全文翻译”即可查看 SSE 流式生成进度并随时点击“停止生成”保留已输出内容。全文翻译默认采用**段落级对齐双语对照**（自动保护 `<pre>` 代码块原样排版，支持一键切换“双语对照 / 仅看译文”与复制完整译文；若长文分段偶有漏译会自动单段补译，绝不把残缺译文写入缓存）。

左侧边栏点击“每日简报”可汇总过去 24 小时未读文章按主题生成简报，点击条目即可跳回对应文章阅读，也可开启每日定时自动生成。

## Linux.do 论坛阅读适配

在“选项 → 订阅源”展开 **LINUX DO** 即可直接浏览并订阅最新主题、热门分类、自定义标签以及每小时热门增量榜单。阅读 Linux.do 主题帖时，本地阅读器主楼底部提供 **「展开后续回复楼层」** 按钮，无需跳出网页即可在原文下方顺畅追读后续楼层回帖；文件夹视图还会自动合并同一帖子跨源抓取的重复副本。

注：公开的分类、标签、最新主题与榜单抓取无需登录即可正常使用；高等级受限帖因内嵌窗口可能触发站点 Cloudflare 人机验证循环，遇到受限提示时可直接点击“外部浏览器打开”在系统日常浏览器中阅读。
